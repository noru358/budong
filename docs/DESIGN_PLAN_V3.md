# V3 제품 기획과 화면 구조

기준일: 2026-10-02, 한국시간. 사용자가 V2 디자인을 거부하고 디자인·UX 팀에 제품 기획부터 다시 맡겼다. 기존 CSS를 덧붙여 외형만 고치는 방식을 중단하고, 첫 화면의 목적·정보 구조·탐색과 선택 흐름을 다시 구성했다.

## 제품의 핵심 작업

사용자가 **서울 정비사업 구역을 찾아 공식 근거를 확인하고, 자신의 물건에 필요한 자금을 계산·비교하는 개인 검토 도구**다. 첫 방문부터 실제 검색과 탐색을 시작한다. 설명용 hero·3단계 온보딩·반복 추천 카드가 첫 작업을 밀어내지 않는다.

| 사용자 작업 | V3 화면과 선택 |
|---|---|
| 구역 찾기 | 홈에서 검색어·자치구·사업유형을 함께 조정하고 연속 목록을 본다. 전체/최근 본 구역을 선택한다. 검색 결과 수와 포털 관찰일을 구분한다. |
| 위치와 맥락 보기 | 데스크톱은 목록 옆 넓은 지도와 선택 구역 요약을 함께 유지한다. 모바일은 목록/지도 전환을 사용한다. 대표지번만으로 좌표를 만들어 표시하지 않는다. |
| 선택한 구역 검토 | 목록 선택 시 데스크톱 요약을 갱신한다. 별도 상세 화살표로 정식 상세를 연다. 모바일 목록 선택은 상세로 바로 간다. |
| 공식 사실 확인 | 상세는 사업현황→고시·근거→내 물건→참고자료 순서다. 권리·사업유형·시행방식은 옆 보조 영역에 둔다. 관찰일·효력일·최신성·첨부자료 검토를 별도로 표시한다. |
| 자금 입력 | 취득·추가자금·매도·근거/가정의 입력 구간을 유지하고 구간 바로가기를 제공한다. 입력 아래 도움말, 만원 단위, 원 환산, 개별 오류, 초안 저장을 지원한다. |
| 결과 읽고 비교 | 저장한 물건을 보관함에서 고른다. 지금/추가/최대 자기자금 등 같은 기준의 요약과 물건 비교를 먼저 보여주고 시간표·세부근거·가정으로 확장한다. |
| 백업과 복원 | JSON을 검사하고 전체·신규·기존 유지 개수를 확인한 뒤 복원한다. 동일 ID는 현재 값을 유지한다. 지도 자료와 물건 백업 범위를 구분한다. |
| 출처 조건 확인 | 별도 출처 화면에서 개인·상업·가공 조건, 검토일, 원문·조건 링크를 확인한다. 현재 서버 이용 모드를 표시한다. |

## 인터페이스 결정

- 기존 녹색·크림색 마케팅 구성을 제거하고 흰 작업면, 중립 회색, 남색 계열의 선택/행동 색을 사용한다. 결과의 투자 우열을 색으로 판정하지 않는다.
- 상단 브랜드·도구 영역과 작은 주 메뉴, 실제 작업 toolbar를 분리한다. 홈과 동일한 검색 화면을 또 하나의 메뉴로 노출하지 않는다. 기존 검색 route와 DOM selector는 호환 목적으로 남겼다.
- 목록은 개별 상자들의 격자로 끊지 않고 연속 행으로 보여준다. 공식 구역명은 임의 축약하지 않고 줄바꿈한다.
- 중요 수치는 동일 서체·오른쪽 정렬·같은 열에서 읽는다. 상세 정보와 표는 필요할 때 펼치고, 표의 가로 이동은 표 안에서만 일어난다.
- 구역 상세의 권리 목록은 확인할 항목의 상태를 먼저 보여주고 설명을 펼친다. 근거가 없는 단계 날짜나 권리를 채우지 않는다.
- 모바일은 4개 주요 화면 하단 메뉴, 안전 영역, 목록/지도 전환, 입력 단계 toolbar와 저장 동작을 제공한다.

## 데이터와 기능 계약

지도는 별도 `map_workspace` 모듈의 HTML/mount/cleanup 계약으로 붙였다. 배경지도·사용자 위치·직접 작성한 참고경계·검토된 외부 경계의 출처와 의미를 구분한다. 상세의 주변 자료는 구역 ID를 기준으로 자치구 월별 거래/필지 참고 조회를 요청하며, RH/APT/SH를 사용자가 고른다. 반환 범위 완료 여부는 구역 귀속 검증으로 해석하지 않는다.

물건 입력은 중간 대출 원금 상환·보증금 반환을 지원한다. 이 항목은 대출 충당 0, 매도 상환액은 중간 정산을 뺀 잔여액으로 계산한다. 수수료는 별도 비용이며 신규 보증금·리파이낸싱은 현재 입력 형식에서 지원하지 않는다.

## 확인 범위

격리된 Mac Google Chrome에서 홈·상세·입력·분석을 1440/390/320px, 출처 20개를 320px에서 확인했다. 가로 넘침과 페이지 오류가 없었다. 물건 입력·저장·분석과 백업 검사·기존 ID 유지 복원을 직접 실행했다. 자동 지도 QA는 외부 OSM 타일 요청을 차단하고 fixture로 대체했다. 실제 지도 이미지 확인과 전체 회귀 검증은 부모 에이전트의 통합 검증으로 보고한다.

실제 사용자 인터뷰·전체 접근성 인증을 수행했다는 주장은 하지 않는다. 연구 출처와 관찰/미검증 구분은 [RESEARCH_V3.md](./RESEARCH_V3.md)에 기록했다.
