# 디자인·UX 리서치와 V2 반영

검토일: 2026-10-02, 한국시간. 사용자가 유사 부동산 서비스와 디자인·UX가 인정받은 서비스를 공부하고 실제 앱에 반영하도록 요청했다. 공식 제품과 공식 디자인 자료를 확인하고 Mac Google Chrome의 격리 프로필에서 실제 화면을 관찰했다.

## 실제 반영

- 데스크톱은 상시 사이드바와 넓은 작업 영역, 모바일은 5개 하단 탭과 안전 영역을 사용한다. 기존 5개 화면과 경로를 유지한다.
- 홈은 검색→공식 근거→내 자금 검토 순서를 보여준다. 내 물건이 없을 때 시작 동작을 제공하고, 가상 예시는 별도 진입으로 명시한다.
- 구역 카드는 사업유형·자치구, 공식 이름·주소, 관찰한 단계·날짜의 위계를 갖는다. 상세 검토 대상이 투자 우선순위를 뜻하지 않는다고 표시한다.
- 검색은 44개 구역을 모두 볼 수 있고, 자치구·사업유형 필터를 검색어와 함께 URL에 기록한다. 필터는 실제 seed의 값으로 구성하고 초기화할 수 있다. 검색 지원 범위는 기존 제한을 유지한다.
- 상세는 공식 관찰 요약, 내 물건·고시·권리 바로가기, 유형/시행방식 설명, 법적 효력일·첨부 검토 상태, 미확인 권리 목록을 보여준다. 일반 법령 링크가 개별 권리의 입증이 아님을 표시한다.
- 입력은 취득·추가자금·매도·근거/가정의 4구간 바로가기와 하단 저장/계산 확인 버튼을 제공한다. 바로가기는 입력에 포커스를 옮긴다. 계산식, 만원 단위, 알 수 없는 값의 처리, 초안 저장은 유지한다.
- 비교는 선택 항목과 동일 지표의 표를 한 패널로 묶고, 물건이 하나인 경우 두 번째 물건이 필요하다고 안내한다. 수익률에 색이나 점수로 우열을 매기지 않는다.

## 검증과 다음 연구

Google Chrome에서 1440px·390px·320px 홈/입력을 캡처해 확인했고 페이지 가로 넘침이 없었다. 동작구 필터 결과 8개, URL 연결, 구역 상세 진입, 입력 3구간 바로가기 포커스와 페이지 오류 0개를 확인했다. 전체 입력·저장·비교 검증은 부모 에이전트의 통합 브라우저 결과를 별도 보고한다.

후속 사용자 조사는 실제 사용자가 ‘관찰일/효력일’을 구분하는지, 빈 값과 0의 차이를 이해하는지, 자금 입력을 중단하는 지점이 어디인지 확인해야 한다. 외부 API 성공·공식 경계 확보·실제 매물 검증·전체 접근성 인증은 이번 디자인 작업의 결과로 주장하지 않는다.
