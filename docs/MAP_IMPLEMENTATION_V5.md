# 실제 구역 지도 V5

2026-10-03. 배경지도만 있었던 V4에서 서울시 GIS 행정 참고경계42개로 개선했다. 재개발닷컴 실제 군집·라벨·선택·상세 패널은 디자인팀이 직접 관찰했고 적용 근거와 관찰 한계를 DESIGN_COMPARISON_V5에 기록했다.

## 구현

`web/map_workspace.mjs`는 검증된 nativeGeoJSON만 표시하며 출처 policy에 서버의 runtimeContext를 전달한다. 사업유형색/점선/선택 외곽/이름·관찰단계·행정참고 라벨을 함께 표시한다. 줌<=12 자치구별 실제 연결수 군집,13 선택 라벨,>=14 전체 구역 라벨을 사용한다. 초기 route 전 경계 파일을 읽어 직접 URL 선택도 해당 구역으로 이동한다. 검색/자치구/사업유형은 목록과 레이어를 함께 필터한다.

실제 브라우저 검증에서 라벨이32px로 축소되는 문제, 범례와 출처 겹침, 저배율 선택 tooltip이 군집 클릭을 가리는 문제를 발견했다. 고정 최소 라벨 너비, 별도 범례/출처행, 저배율 선택 군집 강조로 각각 수정했다. 선택 경계에는 SVG button 의미·키보드 Enter/Space·aria-pressed를 적용했다.

`src/map_data.mjs`는 registry에 의해 허용된 종류와 geometry를 검사한다. 새 경계는 ADMIN_CANDIDATE이며 legal_boundary_verified/current_membership_verified/rights_eligibility_verified 모두 false. 좌표의 변환·클리핑·단순화를 하지 않았다. 원천 사업장 identity 검증과 법적 현행 경계 검증을 혼동하지 않는다.

`/api/map-config`는 직접 loopback/Host 검사로 LOCAL_PRIVATE를 부여한다. 개인 GIS 파일은 같은 검사와 PERSONAL 모드를 통과해야 제공하며 no-store로 응답한다. 이중 슬래시·symlink 별칭도 실제 경로에서 검사한다. Git 제외된 파일은42개 검토 식별자만 조회하는 `npm run map:load`로 로컬 복원한다. 실패 시 기존 파일을 보존한다.

## 완료와 미완료

실경계42/44·우선5 연결, 경계/라벨/군집/필터/선택은 통합했다. 미연결2는 지도에 억지로 표시하지 않는다. 배경지도는 OSM 현재 뷰포트 요청·출처 표시·실패 재시도를 유지한다. 지도 내 전체 거래/사업 탭, 동별 군집, 지도 화면 내 목록 범위, 역 검색, 전수 사업장 확장은 미완료다. 경계 좌표의 외부 공개 재사용 허락도 미확보다.

## 검증

185 단위 테스트 통과. 별도 실제 경계 브라우저 검증은 원천42개 Polygon/행정참고 타입, 직접URL·이름클릭·키보드·군집합/클릭·검색레이어필터·4개너비를 확인했다. 전체 개인 물건 동선도 통과했다. 자동 타일은 fixture이며 실제 지도 네트워크 성공을 대신하지 않는다. 실제 OSM 화면과 Safari 선택은 별도 확인했다. 사용자 연구·실제 모바일 기기는 미검증이다.
