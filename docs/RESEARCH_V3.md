# V3 제품 화면 조사

조사일: 2026-10-02, 한국시간. 공식 서비스의 실제 웹 화면을 Mac Google Chrome의 격리 프로필로 열고, 읽기·검색·선택 화면을 캡처했다. 가입·예약·결제·외부 메시지 전송은 수행하지 않았다. 캡처와 원문 관찰 기록은 checkout 밖 작업 디렉터리에 남겼다. 출처의 사진·로고·컴포넌트 코드를 budong 자산으로 복제하지 않았다.

Apple Maps는 이 환경에서 탐색이 중단됐고 네이버부동산은 404로 연결됐다. 이 두 서비스는 조사 완료 대상으로 세지 않았다. Airbnb의 첫 로딩 skeleton은 완료 화면을 다시 기다려 캡처했으며, skeleton을 제품의 최종 레이아웃으로 평가하지 않았다.

## 조사에서 도출한 기획 판단

직접 관찰과 공식 공개 화면에서 공통으로 유용했던 것은 ‘표현을 꾸미기 전에 사용자가 선택하고 비교하는 작업면을 앞에 둔다’는 구조였다. 이는 **budong 팀의 적용 판단**이며 조사 대상 서비스가 이 구현을 승인·권고했다는 뜻은 아니다.

V3는 장황한 마케팅 hero·3단계 설명·반복 구역 카드를 없애고 실제 검색·필터·목록·지도·선택 요약부터 시작한다. 상세는 근거와 날짜를 읽는 ledger, 입력은 조건을 채우는 작업면, 분석은 저장한 물건과 같은 지표 비교로 역할을 나눴다. 시각 토큰·아이콘·표·입력·선택 상태를 전면 정리했다.

실제 사용자를 대상으로 한 인터뷰·사용성 연구나 A/B 실험은 수행하지 않았다. 후속 연구는 ‘목록과 지도 중 무엇으로 시작하는지’, ‘관찰값과 법적 효력의 차이를 이해하는지’, ‘중간 상환과 잔여 부채 입력에서 어디서 막히는지’를 실제 사용자 작업으로 확인해야 한다.
