# 법무·출처 부서 V5 — 2026-10-03

지도에 구역이 0개였던 상태를 해결하기 위해 KOGL4 SHP와 독립된 서울도시공간포털 공개 GeoJSON 원천을 검토했다. `SEOUL_URBAN_PLAN_GEOJSON` 계약과 로컬 사적 이용 판정을 구현했다. 이는 제공기관의 외부 재사용 라이선스를 확보한 결과가 아니다. 현행 법령에 근거해 영리 목적이 아닌 이 기기 내 사적 참고 범위를 적용한 앱의 검토·제한 계약이다. 공개 비상업 웹서비스와 상업 서비스에는 적용하지 않는다.

## 실제 구현

`src/source_policy.mjs`의 `evaluateSourceOperation(source, {mode, operation, runtimeContext})`에 실행 환경 조건을 추가했다. 새 출처에는 `required_runtime_context:'LOCAL_PRIVATE'`를 등록했고 `legal_basis:'COPYRIGHT_ACT_30_36_94_APP_REVIEW_NOT_PROVIDER_LICENSE'`로 기관 허락과 구별했다. 개인 배지는 **이 기기 내 비영리 사적 이용만 가능**으로 표시한다.

| 환경·작업 | 새 GeoJSON 계약 판정 |
|---|---|
| PERSONAL + 서버가 검증한 LOCAL_PRIVATE + 원래 좌표 지도 보기 | 가능 |
| PERSONAL만 지정, PUBLIC, 환경 값 누락 | 지도 보기 불가 |
| COMMERCIAL + LOCAL_PRIVATE | 지도 보기 불가 |
| 원본 서버의 WGS84 좌표를 임의 변환·클리핑·단순화 | 별도 검토 필요 |
| 대량 수집·제3자 재배포 | 금지 |
| 공개 원문 지도 링크 방문 | 개인·상업 모드 모두 가능 |

부모 구현은 서버 주소와 접속자 주소가 모두 loopback이고 Host도 localhost/127.0.0.1/[::1]인 경우에만 LOCAL_PRIVATE를 부여한다. 요청 JSON·feature properties가 선언하는 환경은 사용하지 않는다. 경계 좌표는 gitignored 로컬 runtime 파일로 두며 공개 Git·배포 패키지에 포함하지 않는다. 파일 경로 직접 접근도 같은 환경/모드 검사를 적용한다. 법무 코드의 단위 검증과 서버의 실행환경 검증은 별도다.

기존 KOGL4 출처는 유지한다. `runtimeContext:'LOCAL_PRIVATE'`를 주더라도 기존 source의 변경금지를 해제하지 않는다. 새 source의 권리 근거를 기존 source나 미검토 VWorld source에 상속하지 않는다.

## 검토한 공식 근거와 해석의 범위

현행 저작권법은 **시행 2026-08-11, 법률 제21336호** 기준으로 확인했다.

- [제30조 사적 이용을 위한 복제](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029423199): 공표된 저작물의 비영리 개인·가정 등에 한정된 복제에 관한 조문이다.
- [제36조 번역 등에 의한 이용](https://www.law.go.kr/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900605247): 제30조 등에 따른 이용의 번역·편곡·개작을 규정한다. 이번 구현은 원본 서버가 제공한 좌표만 사용하며 별도 경계 가공을 허용하지 않는다.
- [제94조 데이터베이스제작자의 권리제한](https://law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0094&lsiSeq=283335&urlMode=lsScJoRltInfoR): 제28~34조 및 제36조 등을 데이터베이스 이용에도 준용한다. 제2항을 대량 수집·공개 서비스의 포괄 허락으로 사용하지 않았다.
- [문체부의 복제권·전송권 설명](https://www.mcst.go.kr/site/s_policy/copyright/netizen/netizen04.jsp): 사적 복제와 인터넷 게시·전송을 구별한다. 공개 비상업 서비스도 사적 이용과 같지 않다는 제한을 반영했다.
- [서울도시공간포털 공개 지도](https://urban.seoul.go.kr/view/map/main.html): 정비사업구역계와 사업 조회를 제공하며 법적 효력이 없는 참고 자료라고 안내한다. 이를 공식 법적 경계나 모든 필지의 현행 포함 관계로 승격하지 않았다.

제30조의 적용은 실제 비영리 목적·사용범위에 달려 있다. LOCAL_PRIVATE는 공개·전송을 막는 구현 조건이며 모든 이용목적이 제30조에 해당한다고 보장하는 판결이나 제공기관 확인이 아니다. 영리업무·매매 영업·타인에게 공유할 자료 작성용으로 사용하지 않는 범위로 제한한다. 상업 전환 전에 원천 데이터의 개별 재사용 허락을 확보해야 한다.

공식 [공공누리 유형안내](https://www.kogl.or.kr/info/license.do)는 제4유형의 변경금지를 내용과 형식 변경 모두에 적용한다고 설명한다. 따라서 기존 KOGL4 SHP를 GeoJSON으로 바꾸는 작업을 자동 허용하지 않았다. 공개 서비스에서 WGS84 GeoJSON을 직접 받은 경로는 SHP 변환과 별개지만, 공개 Query 기능만으로 재사용 라이선스를 확보했다고 표시하지 않는다.

## 원천 서비스 추가 조사

데이터 부서는 공식 viewer가 사용하는 `UPIS/20200526_WFS/MapServer/12`의 `UPIS_C_UQ120` 레이어에서 `f=geojson`, `outSR=4326`으로 서버가 직접 반환한 Polygon을 실제 확보했다. 초기 표본은 청파2·상도15·공덕6·한남5·흑석9의 5개이며, 데이터 부서는 seed 44개 중 42개를 원출처 행과 연결해 native Polygon을 확보했다. 좌표 없는 identity mapping의 mappings 42개와 데이터 부서 검증 기록을 확인했다. 실제 UI 표시 개수는 별도 통합 검증 결과를 따른다. 좌표는 법무 문서나 Git에 복제하지 않는다.

VWorld의 구버전 dev 약관 주소는 현재 메인으로 연결됐다. footer script의 실제 주소를 따라 [현재 이용약관](https://www.vworld.kr/v4po_prcint_a001.do)과 [저작권정책](https://www.vworld.kr/v4po_prcint_a006.do)을 HTTP200으로 확인했다. 약관의 시행일은 2023-08-18이며 제19조는 사전 승낙 없는 저장·복사·변경 등을 제한한다. 저작권정책은 공공데이터의 영리 활용을 안내하면서 자료별 자유이용 표시와 미표시 자료의 협의를 구분한다. 이 확인은 UD602의 저장·지도·가공 허락을 개별 확보한 결과가 아니다. 기존 VWorld 정책은 제한 확인 필요로 유지한다. 데이터 부서가 [공식 WMS 레이어 안내](https://www.vworld.kr/dev/v4dv_wmsguide2_s001.do)를 HTTP200으로 확인한 문서에서는 UD602·UD603 항목을 찾지 못했고 정비구역 검색은 시장정비구역 lt_c_ub901만 반환했다. 이는 해당 문서의 확인 범위이며 VWorld 전체 다운로드 목록에 없다는 결론은 아니다.

공식 카탈로그 [인천 정비구역 JSON 공간 API](https://www.data.go.kr/data/15065681/openapi.do?recommendDataYn=Y)는 이용허락범위 제한 없음으로 표시돼 향후 타지역 독립 대안으로 확인했다. 실제 데이터 최신성과 서울 구역 연결은 검증하지 않았으므로 서울 지도 해결 데이터로 넣지 않았다.

원문·조회 응답은 작업 디렉터리 `../legal-v5`에 보관했다. 제94조 개별 조문은 native HTTP200 본문에서 현행 시행일과 준용 조문을 확인했다. VWorld 약관 응답 SHA-256은 `1a70580079aacb340ae74730455b15db046be9db428de466b1b60449a03bc99e`, 저작권정책 응답은 `4fe45e185a54fa048143b82972146cea75ae9a64b7ae1c689e53cfc41c59dcef`다. hash는 조회 응답 동일성 기록이며 진위·최신성·라이선스 판단 자체의 증명이 아니다.
