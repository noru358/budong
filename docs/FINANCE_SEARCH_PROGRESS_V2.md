## 검색: 복합 검색 구현

기존 단일 이름 검색은 `동작구 상도15`처럼 자치구와 구역명을 함께 입력하면 결과가 없었다. 이제 검토된 기존 검색 term들에서 입력한 단어가 모두 맞는 구역을 찾고 일치 이유를 설명한다. 정확한 전체 이름·축약명 검색은 기존 우선순위를 유지한다.

- `동작구 상도15`, `서울 동작구 상도 15`, `동작구 상도15구억` → 상도15구역.
- `양천구 신정동 311`, `강남구 일원동 615-1` → 기존 대표지번 자료의 구역.
- `송파구 상도15`, 틀린 지번, 하이픈이 사라진 지번, 미등록 역명 → 결과를 추정하지 않음.
- 동/리 이름과 바로 뒤의 지번은 한 검색 term으로 묶는다. 다른 공식 구역명 속 숫자로 틀린 지번을 만족시키지 않는다. 주소 형태는 유사명칭 보정을 하지 않는다.
