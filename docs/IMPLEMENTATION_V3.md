## 화면과 개인 작업

탐색은 검색/필터→연속 목록+지도→선택 요약으로 시작한다. 상세는 단계·날짜·공식 근거·권리 확인 항목을 읽고 해당 구역에 개인 물건을 추가한다. 입력은 4개 구간과 저장 동작을 유지한다. 분석은 저장한 물건·동일 지표 비교·자금 시간표·시나리오로 구성한다. 모바일에는 하단 탐색과 목록/지도 전환이 있다.

초안·미확인 금액을 저장하고 재방문·수정·삭제할 수 있다. 백업은 형식·범위·용량·금액·구역 ID·비밀값을 검사한 뒤 기존 ID를 보존하며 병합한다. 파일 오류·저장 공간 오류 때 기존 자료를 덮어쓰지 않는다. 백업 범위는 USER_CASES_ONLY이며 지도 위치/경계는 포함하지 않는다.

중간 대출상환과 보증금 반환은 날짜별 현금 유출·잔여 부채·매도 정산에 반영한다. 원금/보증금 반환을 경제적 비용에 다시 더하지 않는다. 빌리기 전 상환·잔액 초과 상환은 거부한다. 세금·금융비·가격 가정은 사용자가 입력한 값이며 실제 물건 검산은 아직 하지 않았다.

## 지도와 가져오기

Leaflet 1.9.4(BSD-2-Clause)를 저장소에 포함했다. 실제 OSM 배경지도 이동·확대·서울 초기 보기·표시 위치 맞춤, 좌표 또는 지도 클릭 후 개인 위치 저장, GeoJSON 가져오기를 지원한다. OSM 타일은 현재 화면에 필요한 범위만 요청하며 항상 출처를 표시한다. 대량 다운로드·오프라인 수집은 없다.

GeoJSON은 FeatureCollection, EPSG:4326 Polygon/MultiPolygon, 닫힌 ring, 유효 경위도·좌표 개수·파일/feature 상한을 검사한다. feature properties의 `project_id`, `source_id`, `boundary_kind` 등은 `src/map_data.mjs`의 계약을 따른다. 직접 작성한 자료는 USER_INPUT / USER_DRAWN이며 공식 경계가 아닌 사용자 가정으로 표시한다. 등록된 제3자 자료는 원문 URL·검토일·이용조건/출처 표시 등 메타데이터와 신뢰된 source registry 판정을 요구한다. 업로드 파일의 `use_policy`나 허가 플래그가 원출처 정책을 덮어쓰지 못한다. 형식 변환 여부와 지도 표시를 별도로 검사하며 변경 금지 자료는 개인 모드에서도 가공하지 않는다.

`data/boundary_import_example.json`은 직접 만든 가상 형식 예제다. **실제 5구역 경계를 구현 데이터로 확보한 것이 아니다.** 기본 지도에는 검증되지 않은 구역 위치를 생성하지 않는다.

기본 출처는 OSM 표준 타일이다. 다른 타일 서비스는 `BUDONG_TILE_URL`의 HTTPS 좌표 템플릿, `BUDONG_TILE_REVIEWED=true`, `BUDONG_TILE_ATTRIBUTION`을 요구한다. 자격증명/키가 포함된 URL은 브라우저에 보내지 않는다. 다른 서비스의 이용조건 확인을 환경 플래그가 대신하지 않는다.

## 출처 라벨과 상업 전환

출처·이용조건 화면에20개 출처의 개인 이용·상업 이용·변경 가능 여부·공식 근거·검토일·조건을 표시한다. 기본 `BUDONG_USE_MODE=PERSONAL`, COMMERCIAL에서 해당 작업의 상업 조건을 재검사한다. 알 수 없는 모드는 상업 기준으로 처리한다. 공개 원문 이동·개별 사실 참고·원파일 이용·가공·지도 표시는 각각 판단한다. [정책 상세](SOURCE_USE_V3.md).

이 구현은 상업 미확인 자료 하나 때문에 전체 개인 기능을 차단하지 않는다. 원출처의 변경 금지·미확인 지도 이용허락은 유지한다. 제3자 업로드를 USER_INPUT으로 바꾸거나 출처 표시를 빼서 조건을 해제할 수 없다.
